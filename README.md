# 原神跳一跳

原神对话自动跳过工具：检测到剧情对话自动按空格推进、出现选项气泡自动点击第一个。启动后是一个置顶小窗，F8 一键开关，不影响正常游玩。

## 功能

- 剧情对话中自动空格推进台词
- 对话选项气泡自动点击第一个（最上面）选项
- 仅在原神窗口处于前台时工作，切出去立即停止
- 置顶深色小窗：开关按钮 / F8 快捷键 / F9 退出

> 识别采用「对话界面模板 + 选项气泡模板」匹配，不区分剧情选项与 NPC 功能菜单：检测到气泡即点击第一个，保持行为简单一致。

## 安装与运行

### 方式一：源码运行（需要 Python）

1. 安装 Python 3.9 或更高版本（64 位）
2. 安装依赖：

   ```bash
   pip install opencv-python mss keyboard Pillow pywebview
   ```

3. 运行：

   ```bash
   python skip.py
   ```

### 方式二：安装包

从 GitHub Releases 下载 `Genshin-Skip-Setup-x.y.z.exe`，双击安装即可，无需安装 Python。

## 使用方法

1. 启动后弹出置顶小窗（"原神跳一跳"），同时出现管理员权限弹窗请点"是"
   - 原神通常以管理员权限运行，普通权限下按键注入会被系统拦截，必须提权
2. 进入游戏，遇到剧情对话时按 **F8**（或点击小窗开关）开启自动跳过
3. 再按一次 **F8** 关闭；**F9** 随时退出程序
4. 开关状态实时同步：小窗按钮亮色 = 开启

自动跳过的行为：
- 纯对话文本 → 自动按空格推进（约 200ms 一次）
- 出现选项气泡 → 自动点击第一个选项（感叹号选项优先）

## 自检模式

在 `samples\` 文件夹放入 3 张 1280×720 原神全屏截图（`talk.png` 对话中 / `option.png` 选项界面 / `normal.png` 非对话），运行：

```bash
python skip.py --selfcheck
```

验证判定是否正常，不会注入任何按键。

## 常见问题

| 问题 | 解决 |
|---|---|
| 没有反应 | 确认以管理员权限运行；确认原神窗口在前台；按 F8 开启（小窗变亮） |
| 杀毒软件报毒 | 工具使用键盘钩子与按键注入，属此类工具常见误报，加入白名单即可 |
| 选项被自动点击了 | 当前版本不区分剧情选项与 NPC 菜单，检测到气泡即点击第一个；不需要时可按 F8 关闭 |
