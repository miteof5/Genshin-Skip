# 原神跳一跳

原神对话自动跳过工具：检测到剧情对话自动按空格推进、选项气泡自动点击第一个选项、凯瑟琳等领奖菜单自动静默。启动后是一个置顶小窗，F8 一键开关，不影响正常游玩。

## 功能

- 剧情对话中自动空格推进台词
- 对话选项自动点击第一个（最上面）选项
- 凯瑟琳 / 铁匠 / 阿圆 / 声望等 NPC 功能菜单自动静默，不乱点
- 仅在原神窗口处于前台时工作，切出去立即停止
- 置顶深色小窗：开关按钮 / F8 快捷键 / F9 退出
- 后台 OCR 识别菜单文字，暂停关键词可自定义

## 安装与运行

### 方式一：源码运行（需要 Python）

1. 安装 Python 3.9 或更高版本（64 位）
2. 安装依赖：

   ```bash
   pip install opencv-python mss keyboard rapidocr-onnxruntime Pillow pywebview
   ```

3. 运行：

   ```bash
   python skip.py
   ```

### 方式二：exe 免安装运行（待打包发布）

双击运行即可，无需安装 Python（打包流程见 `打包EXE流程.md`，该文件不随仓库分发）。

## 使用方法

1. 启动后弹出置顶小窗（"原神跳一跳"），同时出现管理员权限弹窗请点"是"
   - 原神通常以管理员权限运行，普通权限下按键注入会被系统拦截，必须提权
2. 进入游戏，遇到剧情对话时按 **F8**（或点击小窗开关）开启自动跳过
3. 再按一次 **F8** 关闭；**F9** 随时退出程序
4. 开关状态实时同步：小窗按钮亮色 = 开启

自动跳过的行为：
- 纯对话文本 → 自动按空格推进（约 200ms 一次）
- 出现对话选项 → 自动点击第一个选项（带"…"或感叹号的选项优先）
- 凯瑟琳、铁匠等菜单界面 → 检测到关键词后静默 30 秒，不点击不跳过

## 自定义暂停关键词

编辑 `data\pause_options.json`，追加关键词即可（JSON 字符串数组）：

```json
["凯瑟琳", "铁匠", "阿圆", "声望", "你自定义的词"]
```

命中关键词的界面不会被自动点击或跳过。

## 自检模式

在 `samples\` 文件夹放入 4 张 1280×720 原神全屏截图（`talk.png` 对话中 / `option.png` 选项界面 / `normal.png` 非对话 / `pause.png` 凯瑟琳界面），运行：

```bash
python skip.py --selfcheck
```

验证三态判定是否正常，不会注入任何按键。

## 常见问题

| 问题 | 解决 |
|---|---|
| 没有反应 | 确认以管理员权限运行；确认原神窗口在前台；按 F8 开启（小窗变亮） |
| 杀毒软件报毒 | 工具使用键盘钩子与按键注入，属此类工具常见误报，加入白名单即可 |
| 不需要 OCR 功能 | 移除 rapidocr-onnxruntime 依赖，未命中关键词时直接点第一个选项 |
